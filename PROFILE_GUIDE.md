# Maintaining this profile

This public repository is named SamiulAlom so GitHub displays its root README on the SamiulAlom profile.

## Update the content

Edit README.md to change your introduction, selected projects and links. The hero and statistical graphics are generated by scripts/update-profile.py. Change its colours/text to customize the design. SVG text is escaped before rendering API values.

## Refresh statistics

Actions > Refresh profile graphics > Run workflow. A daily schedule also refreshes the graphics. The repository's built-in GITHUB_TOKEN is used; no personal access token or external stats host is required. The workflow has contents:write permission to commit its generated images. Only public repositories are queried. Never add private employee records or credentials here.

The generator paginates public repositories and counts primary languages for non-fork repositories. Stars are summed across owned, non-fork public repositories. The contribution chart uses GitHub's rolling-year calendar and its visibility rules. If the API fails, the workflow fails and retains the previously committed graphics, whose timestamp remains visible. GitHub may delay scheduled workflows or disable schedules on inactive public repositories; manual dispatch remains available.
